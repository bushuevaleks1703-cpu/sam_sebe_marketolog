# Точка роста — маркетинговая игра

Статический сайт: один файл `index.html`, без сборки, npm-пакетов, серверных функций и внешних библиотек.

## Запуск локально
Откройте `index.html` в браузере. Для локального сервера можно использовать расширение Live Server в VS Code.

## Публикация на GitHub
1. Создайте новый пустой репозиторий.
2. Загрузите в корень репозитория `index.html`, `vercel.json` и `README.md`.
3. Убедитесь, что `index.html` лежит именно в корне, а не внутри дополнительной папки.

## Публикация на Vercel
1. В Vercel выберите **Add New → Project** и импортируйте этот GitHub-репозиторий.
2. В настройках проекта оставьте **Framework Preset: Other**.
3. **Build Command** оставьте пустым / отключите команду сборки.
4. **Output Directory** укажите `.` (корень проекта).
5. Нажмите **Deploy**.

При последующих обновлениях достаточно отправить изменения в подключённый GitHub-репозиторий — Vercel запустит новый деплой.

## Проверки
- Нет ссылок на локальные файлы, которые не попадут в репозиторий.
- Игровые данные и диагностическое ядро встроены в `index.html`.
- Маршрут заканчивается строго после 8 зафиксированных ответов.
- Кнопка «Завершить маршрут» появляется только после восьмого ответа.
- Результат использует тёмный текст на светлом фоне.
